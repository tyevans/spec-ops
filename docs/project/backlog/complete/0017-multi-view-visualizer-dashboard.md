# TASK-0017: Multi-View Visualizer Dashboard (Gantt, Kanban, PRDs, ADRs, Personas) with Faceted Cross-Filtering

## Summary
Enhance the SpecOps visualizer with multi-tab navigation matching the Runefoble dashboard experience, introducing dedicated views for Gantt & Delivery Timeline, Kanban Backlog Pipeline, PRDs & Feature Matrix, ADR Architecture Radar, and Personas & User Stories Studio, complete with live faceted cross-filtering (by status, name, bounded context, and linked relational entities like "tasks associated with PRD-0001").

## Detailed Objectives
1. **Multi-Tab Navigation Shell**:
   - Navigation tabs: `Relationship Graph`, `Gantt & Timeline`, `Kanban Board`, `PRDs & Features`, `ADR Architecture`, `Personas & Stories`.
   - Zero-reload client-side tab switching preserving search and filter state.
2. **Gantt Chart & Delivery Horizons**:
   - Visual milestone / release horizon timeline.
   - Progress fill bars color-coded by status (Complete in emerald, Refined in amber, Proposed in purple).
   - Grouping toggle: Group by Release/Milestone or by Target Bounded Context.
   - "Hide Done" filter toggle.
3. **Kanban Backlog Pipeline**:
   - 3-column workflow board: Complete, Refined, Proposed.
   - Task cards showing ID, Title, Bounded Context, and PR/commit counts.
   - Interactive click opening rich task drawer.
   - "Hide Done" toggle to focus on active buffer and candidate pool.
4. **PRD & Feature Matrix Explorer**:
   - Searchable view of PRD specifications and checkable outcomes.
   - Filter by status or target persona.
   - Relational chip filters: clicking any PRD highlights or filters to its implementing tasks and linked stories.
5. **ADR Architecture Radar**:
   - Searchable categorized architectural decisions.
   - Filter by domain or status.
   - Relational implementing task pills.
6. **Personas & User Stories Studio**:
   - Persona dossiers with pain points and goals.
   - Filter stories by selected persona.
7. **Modular Invariant Compliance**:
   - Keep all python/js submodules strictly under 500 lines per Hard Invariant 6.

## Definition of Done
1. Standalone bundle generated by `spec-ops visualizer --build` includes all 6 interactive views.
2. Faceted filters operate cleanly across all views (status, text search, and linked object references).
3. Playwright frontdoor tests verify tab switching, Gantt timeline, Kanban board, and relational filtering.
4. `spec-ops health` passes with zero file length invariant violations.
