# TASK-0056: Flow DAG Imbalance Resolution and Adaptive Multi-Column Layout

## Summary
Resolve extreme aspect ratio distortions and visual imbalance in the 2D visualizer's Flow DAG layout when entity counts across stages vary significantly (e.g. 100+ user stories vs single-digit PRDs/personas). Introduces adaptive multi-column stage wrapping, relational sorting by governing entity, center-of-mass vertical alignment, stage lane headers, and auto-fit zoom framing.

## Detailed Objectives
1. **Adaptive Sub-Column Wrapping**:
   - Determine target row limits based on viewport height and wrap imbalanced stages (e.g. user stories) into dynamic sub-columns.
   - Prevent multi-thousand pixel vertical single-column distortion.
2. **Relational Alignment and Sorting**:
   - Sort stories and tasks by governing PRD to group linked items into horizontal bands.
   - Align PRDs vertically to the center of mass of their linked stories to maintain clean, horizontal laminar edge flow.
3. **Stage Lane Headers & Auto-Fit Framing**:
   - Render stage headers and entity counts above each pipeline stage.
   - Auto-fit and center view when switching to Flow DAG or resetting zoom.
4. **Modular Architecture & File Invariant**:
   - Extract layout logic into `layouts_script.py` to maintain all visualizer files strictly below 400 lines per ADR-0002.

## Definition of Done
1. Standalone bundle generated by `spec-ops visualizer --build` includes balanced Flow DAG algorithm.
2. Playwright inspection confirms clean multi-column layout with no vertical stretching.
3. `spec-ops health` reports 0 file limit violations (<500 lines) and 0 proactive warnings (<400 lines).
4. All unit, BDD, and visualizer tests pass cleanly.
